About the test sample

Every result comes from a made-up 3D sample of 240 × 220 × 220 voxels: a sponge-like cylinder in air. Because it's made up, the true movement at every point is known, so we can measure how right each run was. That's rarely possible with real scans.

The sample was squashed, shifted and given a local bulge, then noise was added. Runs were done on a laptop with SPAM 0.8.1.4, so your times will differ.

Lesson 3

Phi, the Instruction Card

Bone doesn't only slide. It also squashes, stretches, leans and turns. SPAM keeps all of that on one small card.

A card of instructions

Imagine giving a friend a card that says exactly how to change a square of rubber: "Slide it this far, squash it this much, and lean it a bit." In SPAM, that card is called Phi, written Φ. It's a table of numbers, and every window gets its own.
Bone pattern with the card applied
The same change shown on a grid

Your card, Phi

Blue numbers are F, which changes shape. Orange numbers are t, the slide. With everything at zero, F is 1s and 0s and nothing changes.

Reading the card

PartHow many numbersWhat it means
t, the translation3The slide in z, y and x. This is your displacement.
F, the deformation9Stretch, squash, shear and rotation. 1 means no stretch, and 0.98 means 2% shorter.
Bottom row0, 0, 0, 1Always the same. It makes the maths neat.
So SPAM isn't only looking for 3 numbers. It's looking for 12. If bone is being squashed inside a window, the pattern is slightly squashed too. A plain slide could never match it perfectly, so SPAM lets the window change shape as well.

Reading a real file

SPAM stores this card in its output. Each row of an ldic.tsv file has these columns:

Fzz Fzy Fzx Zdisp | Fyz Fyy Fyx Ydisp | Fxz Fxy Fxx Xdisp

Here's an example card, with made-up numbers:

0.98−0.010.00−4.0
0.001.020.0120.0
0.01−0.011.011.5
0001

Read the top-left number: 0.98 in z means the sample got about 2% shorter along z. The right-hand column shows it also moved 20 voxels in y.

The rule at the heart of the code is im1(x) = im2(Φ.x). Find the point x in the unloaded scan, use Phi to find where it went, and read the loaded scan there. SPAM keeps im1 still and deforms im2 until it matches. Phi usually lands between voxels, so SPAM estimates the grey value from its neighbours, using linear interpolation by default.

Remember this

  • Phi is a 4 × 4 table holding 12 unknown numbers.
  • t is the movement and F is the shape change.
  • Registration finds one Phi for the whole scan. Local DVC finds one Phi per window.

Lesson 3

Local DVC Flags

Three flags shape every run: window size, node spacing and the first guess.

The basic command

$ spam-ldic unloaded.tif loaded.tif -pf reg-registration.tsv -hws 25 -ns 50
FlagMeansDefault
-hwsHalf-window size. Width = 2 × hws + 1.10
-nsNode spacing. The first node sits one spacing in from the edge.10
-pfThe file holding the first guess.none

Vox saysLook at both lines. Small windows are accurate when they work, but more of them fail, because they hold too little pattern. Big windows rarely fail, but they blur the local bulge, so their miss grows. Good settings sit in between. Spacing mostly changes how many nodes you get, and it has little effect on the miss.

Why not always use small windows?

Smaller -hwsBigger -hws
More local detailSteadier, with fewer failures
Needs a lot of textureAverages everything inside it
Faster for each windowSlower. At spacing 25, hws 40 took 25 s against 1.2 s for hws 5

A useful rule: a window should hold several repeats of your pattern. Test a few sizes on your own scans, because the best size depends on the material.

If -ns is smaller than the window width, neighbouring windows overlap. Their results then share voxels, so they aren't fully independent. More nodes doesn't always mean more information.

What if you forget -pf?

Without a first guess, every window starts at zero movement. This sample moved 15 voxels or more, too far for the hiker from Course 1.

Same runConvergedTypical miss
With -pf44 of 440.6 vx
Without -pf0 of 4418.8 vx
Vox saysThat's a dramatic difference from one flag! There's no error message here either. SPAM runs happily and writes a file full of bad numbers, so always check returnStatus.

Remember this

  • -hws trades local detail against steadiness.
  • -ns sets how many nodes you get.
  • -pf is essential unless the movement is tiny.
